# Maintainers

GShare is developed at [BoanLab](https://github.com/boanlab), Dankook University.

| Name | GitHub | Area |
|---|---|---|
| Jaehyun Nam | [@namjh](https://github.com/boanlab) | Overall project, control plane, operator |

Maintainers review pull requests, cut releases, and handle security reports sent to
<namjh@dankook.ac.kr>.

## Becoming a maintainer

There is no fixed quota. Contributors who have landed non-trivial changes across more
than one component, and who review other people's work, can be nominated by an existing
maintainer. Nomination and approval happen in a public issue.

## Areas

Ownership is advisory — it tells you who to ping, not who is allowed to change what.

| Path | Owner |
|---|---|
| `backend/` | control-plane maintainers |
| `operator/` | operator maintainers |
| `frontend/` | console maintainers |
| `charts/`, `deploy/`, `build/`, `.github/` | release and deployment maintainers |
